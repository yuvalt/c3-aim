# Restorer questions, results v3

Answers use only `dist/instructions.md` rules plus the two knowledge files `dist/aim_sheets.md` and `dist/aim_parts.csv` (full 1970 AIM extract, all UPC groups and options, plus per-section fastener lists with 1989 GM Standard Parts sizes where known). No web, no other files.

Grades: ANSWERED = fully from the files; PARTIAL = some answered, rest flagged honestly; NOT_IN_AIM = the AIM wouldn't contain it and the answer says so; NOT_FOUND = the AIM should cover it but I couldn't find it; WRONG = not confident the answer is right.

**2. Door panel off without cracking the armrest: how many screws, where are the hidden ones?**

The panel uses 4 screws 3919999 with washers 140270 along the top (one pair front/middle, one pair at the rear upper corner, items 4/3), 2 screws 9431733 near and below the pull handle (item 6, 10-15 lb-in), and clips 3932809 in slots along the bottom with screw 9425144 (items 5/9). The AIM gives no removal order and doesn't mention the armrest cracking.
Grade: PARTIAL
Reason: fastener count and locations are from K9/K8/K5; removal technique isn't AIM material.
